NFL WEEK 10 PREDICTION HUB

Open index.html in a modern browser.

Files:
- index.html: page structure
- assets/style.css: responsive FotMob-style design
- assets/data.js: matchup and prediction data
- assets/app.js: rendering, filtering and expandable details

An internet connection is required for ESPN-hosted team logos and research links.
To update games, edit the games array in assets/data.js.
