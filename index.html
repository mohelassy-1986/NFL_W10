Why watch
How it works: this single HTML file calls the public JSON used by ESPN's scoreboard pages directly from the browser. No API key, GitHub Action or server is required. The watch score is calculated locally from spread closeness, projected total, teams’ records and national broadcast status. Because the endpoint is unofficial and undocumented, the page includes a clear retry/error state and may require adjustment if ESPN changes its JSON structure.
